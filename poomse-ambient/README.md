# Poomse Ambient

Instrument AU. Quatre sons faits de zéro (rien n'est enregistré) : **Piano** (court), **Violin** (long, tenu), **Pad** (un accord ouvert tenu),
**Forest** (un lieu : oiseaux et vent). Les touches jouent le son ; le lieu est « laissé entrer » par la touche, quelle qu'elle soit.
Dépose ton propre sample sur un pad pour remplacer ce son (clic droit sur le pad : retour à l original). Le pad décide du jeu : note courte, note tenue, accord tenu, ou lieu.

Réglages : Tone, Bloom (le son monte lentement), Tail (la fin), **Loops** (une touche tenue redit sa note, doucement, à une période à elle :
5, 7, 9... temps ; plusieurs touches se décalent comme les bandes de Music for Airports), Chord, Space, Level. Latch garde les touches. Reset remet tout à zéro.
