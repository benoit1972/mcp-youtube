1. Dézippez PoomseClouds-AU-macOS.zip : vous obtenez "Poomse Clouds.component".
2. Copiez-le dans /Library/Audio/Plug-Ins/Components/ (Finder > Aller > Aller au dossier...).
3. Le plugin n'est pas signé par Apple : dans le Terminal, lancez
   sudo xattr -dr com.apple.quarantine "/Library/Audio/Plug-Ins/Components/Poomse Clouds.component"
4. Relancez Ableton Live (Réglages > Plug-ins > Rescanner avec Option) : c'est un INSTRUMENT,
   dans Plug-ins > Audio Units > Benoit > Poomse Clouds (en effet audio, sur une piste audio).
