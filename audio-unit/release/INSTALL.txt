1. Dézippez GlitchGrain-AU-macOS.zip : vous obtenez "Glitch Grain.component".
2. Copiez-le dans  ~/Bibliothèque/Audio/Plug-Ins/Components/
   (Finder > Aller > Aller au dossier... > ~/Library/Audio/Plug-Ins/Components)
3. Le plugin n'est pas signé par Apple : dans le Terminal, lancez
   xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/Components/Glitch Grain.component"
4. Relancez Logic Pro / GarageBand (instrument : Audio Units > Benoit > Glitch Grain).
