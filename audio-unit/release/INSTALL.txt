0. Si vous aviez "Glitch Grain.component" : supprimez-le de ~/Library/Audio/Plug-Ins/Components/ (même identifiant, conflit sinon).
1. Dézippez PoomseGlitch-AU-macOS.zip : vous obtenez "Poomse Glitch.component".
2. Copiez-le dans  ~/Bibliothèque/Audio/Plug-Ins/Components/
   (Finder > Aller > Aller au dossier... > ~/Library/Audio/Plug-Ins/Components)
3. Le plugin n'est pas signé par Apple : dans le Terminal, lancez
   xattr -dr com.apple.quarantine "$HOME/Library/Audio/Plug-Ins/Components/Poomse Glitch.component"
4. Relancez Logic Pro / GarageBand (instrument : Audio Units > Benoit > Poomse Glitch).
